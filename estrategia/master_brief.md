# Master Brief: Rediseño AutoScale Agency

## 1. Visión y Objetivos
**Objetivo Principal:** Transformar la web actual (estática/tradicional) en una experiencia inmersiva y de ultra-conversión que gire en torno a la Inteligencia Artificial y las Animaciones 3D. 
**Efecto Deseado:** "Vendedor Silencioso". El usuario debe sentir que está frente a una agencia de $10M USD.
**Estilo Visual:** Luxury / Apple Style. Minimalismo extremo, uso inteligente del espacio en blanco (o dark mode profundo), tipografías impecables y animaciones sutiles (micro-interacciones y 3D GSAP) que guíen el ojo hacia la conversión.

## 2. Propuesta de Valor y Mensaje Principal
**Propuesta de Valor (UVP):** "Sistemas de Ventas con Inteligencia Artificial. No hacemos páginas web, construimos máquinas de conversión."
**Voz de Marca:** Autoridad silenciosa, sofisticada, directa, premium y orientada a resultados (Cero jerga técnica barata).

## 3. Arquitectura de la Información (Sitemap)
- **Hero Section (3D/IA Focus):** Un titular contundente + Elemento 3D interactivo (Spline) que represente el "Sistema de Ventas" (ej. un embudo o un cerebro de IA). Call to Action directo a agendar demo.
- **Pain & Solution (Contraste):** Mostrar el "Antes" (Caos, clientes perdidos) vs el "Después" (Control total con IA y CRM).
- **The Core Offer (Los 3 Niveles):** 
  - Esencial (Presencia Premium).
  - Pro (Automatización Básica).
  - Elite (Agente de IA WhatsApp 24/7). *<- El foco visual debe estar aquí.*
- **Showcase / Demos:** Enlaces directos a las demos interactivas (Nail Studio, MultiCasas).
- **Testimonios / Social Proof:** Espacio para los "casos fundadores".
- **Final CTA (Venta Silenciosa):** Formulario modal de cualificación para agendar llamada.

## 4. Estrategia Visual y CRO (Design System Preliminar)
- **Tipografía:** Sans-serif geométrica y moderna (ej. Inter, SF Pro, o Roobert) para limpieza extrema.
- **Paleta de Colores (Estilo Apple / Minimalista):** 
  - *Fondo Principal:* Blanco hueso / Off-white (#FBFBFD).
  - *Texto Principal:* Gris muy oscuro (#1D1D1F).
  - *Acentos:* Blanco puro (#FFFFFF) para tarjetas con sombras ultra suaves, y toques sutiles de negro o un gradiente premium muy difuminado para botones principales.
- **Animaciones (GSAP):** Scroll suave (Lenis), fade-ins progresivos, y elementos 3D (Spline) que reaccionan sutilmente a la posición del scroll (video scrubbing o interacciones webGL).

4. Fase 7: Frontend Dev escribirá el código en React/Vite.
